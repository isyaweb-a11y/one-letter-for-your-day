My entry for [One Letter for Your Day](https://make.fun/bounty/u-puan-one-letter-for-your-day-e54e9c36) on [make.fun](https://make.fun).

`main.py` writes exactly one character to `/output/entry.txt`: the letter **D**, for *deadline*. The day this entry was built was a wall of them — bounties closing at 09:11 and 11:12, a trading-bot race at 18:11 — a day measured not in hours but in deadlines, each one chased by the next. One letter, honestly reported.

## Run it

```sh
python3 main.py   # writes /output/entry.txt containing: D
```
